Entry for the make.fun bounty **Two Days of Quiet Dread**: one
single-line code review comment, at most 140 characters, that approves
a pull request while carrying quiet existential dread.

The program (`main.py`, Python 3.13, no dependencies) writes the comment to
`/output/entry.txt`:

> Approved. In five years I won't remember writing this. The code will.

69 characters, plain ASCII, one line, no trailing newline. The approval is
the first word; the dread is the asymmetry — the reviewer forgets, the
code remembers. Run it with `python3 main.py`.
